# Contributing

Thanks for helping keep this list useful for developers working with OpenAI-compatible APIs, gateways, Web UIs, routing, fallback, client configuration, and cost tooling.

## Good Additions

Open an issue before adding a large batch. A good suggestion usually has:

- a runnable quickstart, config, script, template, or stable docs page
- clear relevance to OpenAI-compatible API use, model routing, gateway setup, Web UIs, IDE clients, monitoring, troubleshooting, or cost estimation
- neutral wording that explains the developer use case
- no hardcoded secrets, affiliate redirects, unsupported benchmark claims, or guaranteed-savings claims

Use this entry shape:

```md
- [Name](https://example.com) - Concrete developer use case in one sentence.
```

## TKEN-Related Entries

TKEN-related resources can be listed, but they must stay visibly disclosed and reviewed under [CURATION.md](CURATION.md). Do not imply that TKEN is officially affiliated with OpenAI, Anthropic, ChatGPT, Claude, LiteLLM, Open WebUI, Continue, Docker, Vercel, Railway, GitHub, or other named tools.

## Local Checks

Run before opening a pull request:

```powershell
npm run check
```

If you add marketing CTAs, use `https://www.tken.shop/`. If you add developer endpoint examples, use `https://www.tken.shop/v1` only where a base URL is needed.

## Public Movement

This contribution guide does not authorize public promotion, upstream awesome-list submissions, directory submissions, social posts, comments, ads, direct messages, or paid placements. Those actions need explicit owner approval for the exact target and wording.
